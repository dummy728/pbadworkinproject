Deskripsi Aplikasi

Sistem Peminjaman Kendaraan merupakan aplikasi web sederhana untuk membantu pengelolaan informasi kendaraan.

Aplikasi ini dikembangkan sebagai sarana pembelajaran pengembangan web menggunakan HTML, CSS, dan JavaScript.

Data Kendaraan

Menampilkan informasi kendaraan yang dikelola.

Status Peminjaman

Mengetahui apakah kendaraan tersedia atau dipinjam.

Catatan Petugas

Menyediakan informasi tambahan tentang kendaraan.
